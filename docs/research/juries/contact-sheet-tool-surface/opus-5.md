🗳️ **Juror 1** (Opus 5) — **VOTE: Q1: `--from`/`--to`, half-open `[from, to)`, same wording as `query`/`preview`/`render`; no defaulting — a lone `--from` or lone `--to` is an error, not "to the end". Q2: (a) — the `--from`/`--to` pair *is* the mode; `--at` with either is refused, and the refusal lives in the verb, not in clap. Q3: Both surfaces, unchanged from single-frame `frame`. Q4: Refuse `--full` with a range as an invocation error that names why; never silently ignore, never re-purpose. Q5: `--png` carries over unchanged; `--json` carries over with its existing meaning (JSON *instead of* the text caption, sheet returned either way) — and the plain-text form must carry the full `rule`/`skipped`/`coverage`/`blind_to` content in fitted prose; the disclosure may not live only behind `--json`. Q6: Settle the spelling and the illegality now — if per-tile crop ever ships it is the existing `--crop` composed with the existing range and never a new flag name, and `--crop` + range is refused today as not-yet-legal pending #406/#402; #406 keeps only whether the mode ships and what it discloses. Q7: (a) — the per-tile label discharges the attribution obligation, and ADR-0011 is amended here to say the obligation is "the agent must be able to attribute what it sees", satisfied per-tile by #400's label plus ADR-0094's per-tile provenance block.**

**Reasoning:**

**Q1.** Three verbs already spell a span `--from`/`--to`, half-open, in nearly identical sentences. A fourth spelling would make the surface teach two range grammars for one clock, and every extra vocabulary item is context an agent pays for on every turn. The trial agents' `--per-state` / `--each-cut` are not range spellings at all — they are *selection-rule* names, and ADR-0094 already fixed the selection rule as the only one the verb has, with no `--visual` flag. Naming the flag after the rule would imply a sibling rule exists to switch to. Their instinct is satisfied by the disclosure sentence, not by the flag name. On defaulting: "omit `--to` means to the end" is exactly the silent-generosity failure the fixture punished — ADR-0095 says the refusal is the *common case* past ~65 s, so an implicit "to the end" would turn most first invocations into an overflow refusal on a range the caller never asked for. Requiring both keeps the caller's intent explicit and keeps the refusal attributable to something they typed.

**Q2.** `measure` is the precedent: exclusive argument groups, resolved in the verb so both surfaces inherit. The mode here is not a capability toggle, it is a different question shape — "what does it look like at an instant" versus "over a span" — and the arguments already distinguish those unambiguously. A `--sheet` flag adds a second thing to get wrong (`--sheet` with `--at`, `--sheet` with no range, a range with no `--sheet`) and adds a schema field that costs context every turn to encode information the range arguments already carry. `--at` plus `--from` is malformed, not a precedence puzzle; refuse it and name both.

**Q3.** The one trial datapoint is not evidence for CLI-only — it is evidence that *both* status-quo paths were bad, which the agent said itself. The sheet deletes the reason it chose the CLI: one call, not 18, so the round-trip argument evaporates, and MCP hands the image back in the result instead of charging an extra file read per frame. Meanwhile the >20-image-block clamp is an MCP-side correctness cliff — dropping MCP would leave the surface where the corruption happens without the fix. CLI keeps it for the human and for scripted use, and `--out` stays required there for the reason already recorded: no ADR names a filename, and a read must not write into someone's project directory uninvited.

**Q4.** `--full`'s entire documented content is "spend the difference." ADR-0095 measured that there is no difference: 1518–1568 of 1568 tokens at every tile count from 4 to 48. And tiles are already rasterized at true project pixels. So the flag's referent does not exist in range mode. Silently ignoring it is the exact failure mode the whole effort is built against — the third agent's sampler was blind and its silence read as coverage; a flag that accepts "give me full fidelity" and quietly does not is the same lie in miniature. Re-purposing it (say, to mean the 140 px floor) would smuggle a legibility knob in under a resolution name and would collide with ADR-0095's derived-count rule. Refuse, and let the refusal say the sentence worth learning: in range mode the currency is served tile width, which is derived, not chosen.

**Q5.** `--png` is orthogonal to everything the sheet decides: #397 confirmed encoding is token-irrelevant, and lossless pixels for latency is a real trade on a sheet too (arguably more real, since JPEG ringing on 180 px tiles is the noise floor for exactly the fine-detail class that dies at ~140 px). Carry it unchanged. `--json` also carries unchanged *as a serialization choice* — but it must not become the gate on the disclosure. ADR-0094 says every answer carries the structured disclosure "plus one sentence of prose restating it"; ADR-0095 says every range answer discloses the served tile width and its rung. If the text form only summarized, then the default invocation — the one an agent reaching for pixels will actually use — would be the one whose coverage claim is unfalsifiable, and "any selection rule this feature adopts can fail the same way, and the disclosure is the only defence" would be defended only for callers who happened to pass a flag. The cost is bounded and measured: 1,413 characters for a whole sheet answer. Text form carries rule, skipped with reasons, dropped audio-only boundary count, untiled keyframe count, served tile width and rung, and the fixed `blind_to` enumeration, in fitted prose; `--json` renders the same facts canonically instead of the prose.

**Q6.** Settle the cheap half now, decide nothing #406 owns. What this ticket exists to fix is the shape of the tool surface, and leaving a flag *name* open is how you end up with `--crop-band` shipping beside `--crop` and two ways to say one thing forever. Composition is also the only option consistent with ADR-0095, which supplies the constant a cropped sheet's count would be derived from — it presupposes the same crop rectangle semantics. What #406 keeps is everything substantive: whether the mode ships at all, and what a cropped sheet must disclose about the band it cannot see — which matters because a cropped sheet *looked clean* while the wrong-photo defect had vanished from it. Until #406 lands, `--crop` with a range is refused with a named not-yet-legal code (class per #412), which is honest and reversible; shipping it before the disclosure exists would ship the blindness without the warning.

**Q7.** (c) is unaffordable and, worse, self-defeating: 28,410 characters is the uncosted 20.1x, and the sheet's whole claim is that one call replaces eighteen — paying eighteen captions keeps the cost while pretending to remove it. (b) is closer than it looks and I would accept it as a friendly amendment rather than an alternative: ADR-0094's mandated per-tile provenance, plus the dropped-audio-boundary count, essentially *is* a range-scoped cut list, so (b)'s content largely arrives already. But (b) alone does not discharge ADR-0011's actual worry. That worry is misattribution — looking at a defect and blaming the wrong element. Misattribution is a per-tile hazard: a range-level block tells you which elements appear somewhere in the span, which is precisely the inference that lets you pin tile 7's bad pixels on an element that was not on screen at tile 7. So the obligation has to be discharged tile-locally, which is (a). ADR-0011's words forbid this, so amend it — that is the correct instrument here, since ADR-0095 explicitly routed the ADR-0011 amendment to this ticket and this repo amends rather than rewrites. The amended obligation should be stated as the invariant ADR-0011 was actually protecting — the agent must be able to attribute what it sees to what produced it, without a second call — and then say that at single-frame scale that is the `query --at` block and at sheet scale it is #400's fitted per-tile label together with the structured per-tile provenance. Note the dependency this creates and state it: (a) makes #400 load-bearing for ADR-0011 compliance, so a label that is unreadable or that drops the identifying field is no longer a cosmetic defect but an ADR violation.

**Trade-offs:**

**Q1.** Consistency costs the trial agents' own words, and there is a real risk they reach for `--per-state` and get an unknown-flag error on first contact; mitigate in the error text, not the flag name. Requiring `--to` costs one keystroke and one round-trip for the caller who meant "the rest of it," and it means there is no way to say "show me everything" in one shot — accepted, because on any real-length project that request is a refusal anyway and it is better to refuse the range the caller typed than one the verb inferred.

**Q2.** (a) costs discoverability: nothing in the flag list announces "there is a sheet mode," whereas `--sheet` would advertise itself in the MCP schema an agent already reads every turn. It also means the mode's *name* lives only in the docs and the disclosure prose. Accepted because the schema field would be permanent context rent, and because two ways to express one mode is a worse legacy than one under-advertised one. (b)'s cost is the combinatorial refusal surface plus the implication that the sheet is optional decoration on a range rather than what a range means.

**Q3.** Both costs double implementation and doubles the refusal paths to keep in sync — and the verb-level rule placement is what makes that affordable, which is why it is not negotiable here. MCP-only would cost the human and every scripted use, and would orphan `--out`. CLI-only would cost the agent the inline image, force the extra file read the trial agent already complained about, and leave the >20-block clamp unaddressed on the surface that suffers it.

**Q4.** Refusing costs an agent that habitually passes `--full` a wasted turn, and it hard-codes a tier fact (1568 saturation) into a permanent surface rule — if a future tier serves more pixels, the refusal is the thing to revisit, and the ADR should say so rather than letting a silent flag quietly become meaningful again. Silent-ignore costs nothing up front and buys a false belief, which is the most expensive thing in this whole effort. Re-purposing costs the derived-count guarantee.

**Q5.** Making the text form carry everything costs roughly a kilobyte on every range answer and some duplication between prose and JSON — cheap against 1,413 total, and against a sheet whose coverage claim no one can check. It also constrains #412's codes to be renderable as prose, not only as enum values. Letting the disclosure hide behind `--json` would have been the smaller diff and the smaller default answer; it buys that by making the default answer the untrustworthy one.

**Q6.** Fixing the spelling now costs a decision made slightly ahead of the evidence: if #406 concludes the band needs its own aspect-aware semantics, "reuse `--crop`" may have to be amended. Low risk, since ADR-0095 already derives from the same rectangle. Saying nothing costs a live chance at a duplicate flag name and leaves an undefined behaviour — `--crop` plus range — reachable today with no stated answer, which is worse than a named refusal.

**Q7.** (a) costs an ADR-0011 amendment on its most emphatic sentence, and it transfers load onto #400, which is still open — so this ticket must record that transfer explicitly or the guarantee falls in the gap between two tickets. It also genuinely gives something up: a fitted label cannot carry a full resolved stack, so an agent that needs the whole stack for one tile must make a second single-frame `frame --at` call at the tile's instant — which ADR-0094's non-synthetic instant rule is exactly what makes possible, and which is the right price. (b) costs less amendment but does not prevent cross-tile misattribution, the specific harm. (c) preserves the letter of ADR-0011 and pays 20.1x plus the uncosted-budget problem #397 named, for an answer no agent will read in full. (d) — I looked for a fourth option and the only candidate is "label plus stacks on request behind a flag," which reintroduces a suppressible caption from the other direction and I reject it.
