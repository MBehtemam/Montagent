🗳️ **Juror 3** (Fable 5.1) — **VOTE:**
**Q1:** `--from`/`--to`, half-open `[from, to)`, identical words to `query`/`render`/`preview`; both required together, omitting `--to` is a verb-level refusal, not "to the end"; no `--per-state`/`--each-cut`.
**Q2:** (a) — the pair is the mode; `--at` with either of `--from`/`--to` is refused in the verb (the `measure` pattern), no `--sheet` flag.
**Q3:** Both surfaces — MCP returns one image block, CLI writes one file to the already-required `--out`.
**Q4:** Refuse `--full` with a range as an invocation error whose message names why (tokens saturate at every tile count; tiles are already true-pixel).
**Q5:** `--png` unchanged; `--json` unchanged in meaning (JSON instead of text, image either way); the plain-text form must carry the full `rule`/`skipped`/`coverage`/`blind_to` content — prose-summary-only is rejected.
**Q6:** Settle the spelling only: if per-tile crop ever ships it is the existing `--crop` composed with `--from`/`--to`, never a new flag; until #406 lands, `--crop` plus a range is refused as not-yet-legal, naming #406 — never silently ignored.
**Q7:** (d) = (a) plus a range-level block: the tile label discharges the *on-image* half, and one re-merged visual cut list (one line per tile: instant, run, presence set as element ids) in the unconditional disclosure discharges the *attribution* half; ADR-0011 is amended to state the obligation as "the agent can attribute every pixel it sees", not "18 stacks". Not (b) alone, not (c).

**Reasoning:**
- **Q1.** The trial agents' spellings (`--per-state`, `--each-cut`) name a *selection rule*, and ADR-0094 has already fixed that rule as the only one — a flag whose sole value is the default is a flag with nothing to say, and it would invite the `--per-cut`/`--per-keyframe` family ADR-0094 deliberately closed (keyframes are a separate additive flag). The range is the thing that actually varies, and three verbs already spell it one way; a fourth spelling costs every agent a schema read for no information. On defaulting: ADR-0095's own risk says the refusal is the *common* case past ~65 s, so a defaulted `--to` = end-of-project would make the very first call on any real project a refusal. Requiring `--to` forces the caller to name a span before the verb can tell them it is too wide, and matches the three neighbours' "asked for with `--to`" sentence verbatim. Refusing in the verb, not clap, is required by the existing CLI comment — MCP has no clap.
- **Q2.** The only thing a range can return from `frame` is the sheet — motion is out of scope, count is derived, there is no second range product to disambiguate. A `--sheet` flag would be one that must always accompany the pair and can never be omitted with it: pure redundancy, and a second thing to get wrong. `query` is the precedent: the pair *is* range mode. `--at` + `--from` is a malformed ask (two different questions), and the `measure` precedent already says overlap is a verb-level refusal both surfaces inherit.
- **Q3.** The strongest argument for the sheet at all is the >20-image-block clamp, which is an *MCP* correctness cliff — so MCP must have it. The trial agent who stayed on the CLI was performing exactly the ritual this feature deletes and called both options bad; shipping MCP-only leaves that agent with the bad option it already chose. ADR-0011 puts `frame` on both, the rules live in the verb, and the CLI already has `--out` required, so a sheet on the CLI is one file write with no new decision. Cost of "both" is near zero; cost of either "only" is a surface that lies by omission about where the feature lives.
- **Q4.** Silent ignore is the exact failure this project keeps naming — "nothing in the output to suggest otherwise" — and an agent that passes `--full` believing it bought detail will read a 140 px sheet as full-res evidence. No honest new meaning exists: tokens are flat 1518–1568 at every count (nothing to spend), tiles are already rasterized at true pixels (nothing to raise), and composing above the 1568 px served edge is discarded by the API. Refusing with a message that states those two facts teaches the agent the currency in one line.
- **Q5.** `--png` is encoding, token-irrelevant, and lossless pixels matter *more* at 140 px where JPEG ringing can eat the fine-detail class. `--json` keeps its contract. On the disclosure: ADR-0094 says *unconditional structured disclosure plus one sentence of prose* — "unconditional" cannot mean "behind a flag". The default path (no `--json`) is the one most agents take, and the third trial agent's failure was precisely a silence that read as coverage; a prose summary on the default path would rebuild that failure by design. The measured whole answer is 1,413 characters, so the full content in text is cheap.
- **Q6.** If this ticket says nothing, an agent can invoke `--crop --from --to` today and get either a whole-frame sheet (crop silently dropped — the blindness failure, inverted) or a half-scaled sheet via the live #402 defect. The surface must be closed now. Fixing the spelling costs #406 nothing (it was never going to invent `--band`), and recording the composition as not-yet-legal gives the agent a refusal that names the ticket rather than a picture that lies.
- **Q7.** (c) pays 28,410 uncosted characters per call and would be the larger half of the cost — it inverts the feature's purpose. (b) as a bare cut list tells the agent *when* each tile is, not *what* is in it, so the wrong-element attribution ADR-0011 fears is still possible. (a) alone fails because #400's label is *fitted* to tile width — at 140 px it can carry an instant and little else, so the label cannot name the presence set. But the presence set per tile is *already* mandated by ADR-0094 as per-tile provenance, and it is exactly the re-merged visual cut list the feature computes internally. Printing that once (one line per tile) is the sheet-scale equivalent of the `query --at` block: it names which elements produced each tile, and because ADR-0094 chose document-derived instants over the midpoint, any tile's full resolved stack is one reproducible `query --at <instant>` away. The amendment to ADR-0011 should say the obligation is attribution — a stack per image when the image is one frame, a presence set per tile when it is a sheet — and should also correct the half-wrong 2691 sentence while it is open.

**Trade-offs:**
- **Q1.** Consistency costs the obvious convenience of `--from 0` alone; `--from 0 --to <duration>` is one extra number, and the refusal names fitting sub-ranges anyway. `--per-state` would have read nicer in the trial transcript, but it encodes a rule the caller cannot change.
- **Q2.** (a) means a future second range product (if motion ever came to `frame`) would need a new discriminator; that product is explicitly out of scope, and adding a flag then is cheaper than carrying a dead one now. (b) buys nothing today and adds a required-with-required flag.
- **Q3.** Both costs one extra file-writing path and a second place to keep the disclosure identical; CLI-only forfeits the clamp fix; MCP-only strands the bash-loop agent. Note the CLI sheet still pays a file read, which the trial agent disliked — that is inherent to a terminal, not to this decision.
- **Q4.** Refusing means an agent that habitually passes `--full` gets a one-time error instead of a picture; silent ignore avoids the error but manufactures false confidence; a new meaning would have to be invented, and none survives ADR-0095's measurements. Missing fact: whether any client sets `--full` by default — if one did, the refusal would be noisy, but I would still refuse.
- **Q5.** Full disclosure in text costs a few hundred characters per call and some layout work to keep `skipped`/`blind_to` readable without JSON; hiding it saves those characters and reintroduces the one failure the evidence was built to prevent. Not a close call.
- **Q6.** Deciding the spelling now slightly pre-empts #406, which could in principle want a distinct semantics for "band across every tile" versus "crop of one frame"; if it does, it can still reuse `--crop` and document the difference. Saying nothing leaves a live invocation with undefined behaviour on a surface whose whole argument is that it never lies.
- **Q7.** (d) costs a per-tile provenance line that #412 must give a class and #400 must not duplicate on the image; it leaves the resolved geometry a second call away, so an agent chasing a layout defect pays one `query --at` after the sheet — acceptable, since ADR-0011 already demotes `frame` from measuring. (a) alone is the cheapest and is blind at narrow tiles; (b) alone is cheap and unattributed; (c) is faithful to ADR-0011's letter and defeats its purpose.
