# Juror 1 — Fable 5.1

🗳️ **Juror 1** (Fable 5.1) — **Part 1 VOTE: (c) — the answer owes something; not inside `blind_to`; the self-check is the right form, placed as its own fixed line beside the provenance list, with the exact per-tile label string also carried as a JSON field**

**Reasoning:** The effort's destination is that "I checked the whole thing" be an artifact rather than an argument. Haiku's transcript on the 184 px sheet is exactly an argument dressed as an artifact: confident, specific, wrong, and indistinguishable from a real reading by anyone who only sees the transcript. That is the founding failure with the blind sampler swapped for a blind reader, and the effort's settled defence for that failure is disclosure. So (a) misdescribes what is being asked: nobody is asking Montagent to make Haiku see, only to make Haiku's not-seeing *detectable* — by Haiku if it is honest, and by whoever reads Haiku's report if it is not. The label/provenance redundancy already exists for exactly this kind of cross-check; the self-check just names it. It judges nothing about the video (no verdict layer touched), it is a fixed sentence (learnable), and it names a follow-up call (`frame --at` per instant), which is the same shape two `blind_to` sentences already have. (b) is necessary — the floor ADRs must record that 140 px and 8 px are reader-conditional — but an ADR note reaches nobody at call time, and the incident on record says the reader believes what is in front of it. It does not belong in `blind_to`: that block is defined as statements about the selection rule, constant across documents and readers. The self-check is about the rendering-to-reader boundary and its truth varies with the reader. Putting it in `blind_to` would blur a definition the effort has been careful about. Give it its own fixed block — a "legibility" line — printed unconditionally, in text and JSON, with tile 1's exact label text in the sentence and every tile's label string as a JSON field so the check is also mechanical for a supervising agent. The tool description should state the same fact once, in the same words, so the description and the answer cannot diverge the way they did in the prior incident.

**Trade-offs:** It costs one more fixed line on every answer, and a risk the evidence already hints at: a reader that transcribed captions instead of the gutter may also assert "yes, I can read tile 1's label" without reading it. The self-check does not defeat a confident liar; it makes the lie checkable from the transcript, because the exact string is in the text and a second reader can compare. That is the most disclosure can do, and it is what the effort promised. (a) leaves the weak reader's silence-as-coverage exactly where the effort found it, only moved one hop downstream. (b) alone records the truth where no caller will meet it. A stronger alternative — refusing the call or gating on reader identity — is impossible (Montagent cannot know the model) and would be a verdict about the reader, which is the same species of verdict the effort forbids.

🗳️ **Juror 1** (Fable 5.1) — **Part 2 VOTE: No — neither the answer text nor the tool description names a model or model class**

**Reasoning:** The prior binding to "the tier the API serves" worked because it named a documented, stable host property that the caller can look up and that does not change meaning when a product is renamed. A model name is neither: "Sonnet/Opus-class" is a marketing tier that rots on every release and says nothing operational to a reader that is not one of those models. What `frame` can state honestly is the measured capability, not who had it: "labels are set at 8 px as served and tile width is at least 140 px; the floors were set where a reader could transcribe the label; if you cannot, the sheet is below what you can see." That sentence stays true under any future roster. The ADRs are dated evidence records and may name Haiku 4.5, Sonnet and Opus as the readers in the 42-reading experiment — that is history, not spec. The tool description is the worst possible place for a model list: it is precisely where a stale promise once outranked a live fact, and a list of models that "can read this" is a promise that will be stale within months.

**Trade-offs:** The cost is that a caller who wants to know "will my model cope?" gets a capability threshold (8 px type, 140 px tiles) rather than a name to match against, and must run the self-check to learn the answer. That is the honest position: Montagent can measure the sheet, not the caller. "Only in the tool description" is the tempting middle and the wrong one for the reason above.

🗳️ **Juror 1** (Fable 5.1) — **Part 3 VOTE: (i) decide now; the measurement is a later prototype ticket, with the ADR recording the prediction it would falsify**

**Reasoning:** The measurement cannot change the Part 1 decision, only the wording of the self-check. Whether a weak reader owes disclosure of its own blindness does not depend on whether Haiku, specifically, applies it honestly; the self-check's value to a second reader of the transcript holds even if the weak reader lies past it. What the measurement *can* show is that the phrasing invites false agreement, in which case the form changes (for example, requiring the reader to quote the label rather than affirm it). That is a refinement, and the ADR should state the falsifiable prediction plainly — "a reader that cannot transcribe tile 1's label will say so when the answer asks" — so the ticket has something to disprove. Making it a shipping condition (iii) would gate a real feature on a mocked answer read by one weak model, one reading per cell, and the evidence already says Haiku's failure is not a threshold effect; a mock-based negative would not tell you to remove the check, only to reword it. Waiting (ii) blocks the range mode on building the very plain-text answer the decision would specify.

**Trade-offs:** Deciding now risks shipping a self-check phrased in a way a weak reader rubber-stamps, and learning that later. The cost is one rewording of a fixed sentence under an ADR amendment, which is cheap; the cost of (ii) or (iii) is the range mode idling behind a prototype whose best outcome is "keep the wording." The measurement should still run — it is the first real test of the whole disclosure stance against a reader that fails confidently — but as evidence for the next amendment, not as a lock on this one.
