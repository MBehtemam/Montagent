## Method and its limits

- **Network:** `helpx.adobe.com` and `adobe.com` are blocked by this environment's egress policy. The proxy returns 403 on CONNECT, and WebFetch can't reach the host (re-tried in the third pass: `getaddrinfo ENOTFOUND helpx.adobe.com`). The left-nav TOC HTML could not be read, so no row is marked (F) (fetched and read in full).
- **How rows were found:** web searches restricted to `helpx.adobe.com`, aimed at whole chapters. The first pass ran until the shared search budget ran out, the second pass used 44 more queries, and the third pass used 34 queries, one or two per named gap. Each row's title, URL and chapter are as Adobe's search index returned them. A row marked (S) takes its feature list from a search excerpt of that page, so the list is a summary, not a full read. A row marked (T) had only its title and URL returned, so its feature list paraphrases the title.
- **Normalisation:** regional duplicates (`/in/`, `/au/`, `/uk/`, `/ie/`, `/my_en/` …) are collapsed to the global path. Two pages surfaced only under unusual slugs and are kept as returned: `premiere-pro/desktop/…/consolidate-and-archive-projects.html` and `use-premiere-pro-with-other-apps/install-plug-ins-and-extensions.html`. When the only hit for a topic was a legacy `premiere-pro/using/…` page, the row is kept and marked "(legacy URL)". Knowledge-base (`/kb/`), how-to tutorial (`/how-to/`), Premiere Elements, Premiere mobile and Rush pages are excluded, because they are not part of the desktop user guide.
- **Re-tagging in the second pass:** the first pass's 11 UNCOVERED rows were re-tagged. The 6 VR/360 rows became `vr` (ticket #909). System requirements, known issues and troubleshooting became `not-a-feature`. All first-pass rows were built from search excerpts, so they are marked (S).
- **Third-pass tagging:** the four media-cache pages sit under `troubleshooting/media-issues/` but document the Media Cache preferences and purge, so they are tagged `workflow`, not `not-a-feature`. The other new Troubleshooting pages are `not-a-feature`.
- **Area tags:** editing, effects, colour, titles, captions, audio, motion, import, export, ai, workflow, vr, not-a-feature, UNCOVERED. AI-driven features (transcription, Enhance Speech, Remix, Separate Crosstalk, Object Mask, media intelligence, generative tools) are tagged `ai` even when they sit in another chapter.

7. **Sync Settings:** only the legacy `premiere-pro/using/sync-settings.html` page surfaced. Its excerpt says Sync Settings was discontinued from 24.3, so a new-slug page probably doesn't exist.
8. **Film Impact effects:** no dedicated page. The effects are covered by What's new, Effects and transitions changes in 26.0, the effects and transitions reorganization, and Modern transitions.

10. **HDR grading:** no single HDR-grading page. The guidance is split across Color mode and Color Management, Tone mapping, Configure sequence output color space, the legacy Color Management options (HDR workflows) page, and the HDR export row.
11. **Playback resolution:** no page under `render-and-export/`. It is covered by Set display quality and Enable high quality playback (Get started).
12. **Illustrator round trip:** no separate page. Edit Original is covered in Import Photoshop and Illustrator files. Adobe Express and Character Animator pages were not searched.
13. **Troubleshooting:** 17 pages are recorded. Error-message pages beyond these didn't surface, and `/kb/` articles are excluded.
14. **AI Assistant:** search returned only the overview and FAQ, so there are no further sub-pages that could be confirmed.
15. **Outside the third-pass brief, not re-searched:** audio-sync pages beyond Synchronize, a captions import page, and stylise-text sub-pages beyond Create titles and Create text styles.
