## How an edit operation is read

Premiere's editing features are mostly **operations**: a tool that changes several clips at
once. Montagent's agent edits the project's literals itself. The write-tool invariant
([ADR-0011](../../adr/0011-tool-surface-reads-checks-renders.md)) forbids an
`update_element` tool, and `shift` is the one edit Montagent does arithmetic for
([ADR-0005](../../adr/0005-absolute-integer-milliseconds.md)). So this table reads an
operation by mechanism as follows:

- **have** means the result is writable as literals and `validate` checks it. No tool is
  needed for that. Example: a slip changes `source_start` and `source_end` by the same amount.
- **partial** means part of the mechanism is missing. Usually Montagent promises the
  arithmetic but has not built it. Example: `shift` refuses a negative `delta`, so time cannot
  be closed up.
- Pure GUI chrome, such as track height or the Selection Follows Playhead button, is listed. Its
  nearest Montagent mechanism is the `query` cut list or the `frame` contact sheet.

## Notable gaps

1. **`shift` refuses a negative `delta`.** Extract, ripple delete, close gap, shortening ripple
   trims, rearrange edits and ripple speed changes are all partial for this one reason. ADR-0012
   already specifies the mechanism, and `shift.rs` defers it to a follow-up. It is the biggest
   lever in this chapter: six `partial` rows hang on it.
2. **No markers of any kind.** Sequence, clip, range, chapter, segmentation, web-link and
   cue-point markers are all missing, and so are snap-to-marker and hold-on-marker. Chapter
   metadata in the delivered MP4 depends on them (#892).
3. **No multicam.** There is no synced angle set and no sync by audio or timecode. `probe`
   reads no source timecode, so timecode sync has nothing to work from.
4. **Integer `fps` only.** NTSC rates (23.976, 29.97, 59.94) cannot be written as a project
   rate. There is no interlaced output or non-square output PAR either.
5. **Nesting is refused while it carries a clock.** The space-only `nest` (#632) is
   provisional and not in v0.2.0. Subclips are refused as an asset table (ADR-0002); the
   per-element source range gives the same edit result.
6. **Track-level switches are missing:** track lock, track mute/solo/output toggle, element
   enable/disable, and sync lock on a chosen subset of tracks.
7. **Speed interpolation is frame sampling only.** There is no frame blending or optical
   flow, and reversed or ramped audio is refused (ADR-0157).
8. **Adjustment layers are partial.** A blend-mode `rect` tints the backdrop, but no effect can
   filter what lies below an element. No ADR refuses it, so it is open.
9. **Linking separate sound to picture.** A `video`'s own sound always moves with it, but
   double-system audio has no link, merge or per-pair sync check.
