### How the Premiere side was sourced

The first version of this file (#892) was written while helpx.adobe.com was blocked. It rested on
search excerpts, and rows marked † described a page's content from memory. For #911 every row was
re-read against the full text of the pages:

- **The Premiere guide:** the census (#883) fetched all 807 pages of the Premiere 26.5 user guide. This
  area's 33 pages and the three What's-new pages were each read in full, and the whole corpus was
  searched for export features documented elsewhere (smart rendering, the Frame.io upload, LUT export,
  the removed-effects list, the Apple-silicon limitations, the Generative Extend known issues).
- **Adobe Media Encoder:** where a Premiere page defers to Media Encoder for format or option detail,
  the AME page was fetched live from `helpx.adobe.com/media-encoder/desktop/` on 2026-10-10.

Every row's URL is the page that states the mechanism, marked **(F)** for fetched. A row that no page
supports is kept and marked **unconfirmed** (3 rows), never dropped. No † row remains. The
`## Pages covered` table at the end maps every page assigned to this area to the rows it supports.

  the row). Another 14 rows were moved to the page that actually states them (marked *Corrected
  source*), and every row now points to a fetched page. Examples: H.264 has no "High 4:2:2" profile, only Baseline/Main/High/High10. Embedded captions work only in QuickTime and MXF
  OP1a, not H.264. "Chapter markers" are sequence markers written into XMP. Loudness Normalization
  offers three named standards and a true-peak limiter with look-ahead and release, not a free target and
  tolerance. CineForm, P2 and Wraptor DCP are unavailable on Apple silicon. The Timecode effect is
  obsolete and removed rather than "no longer renders". OTIO export is in the 26.x release notes, not
  "26.2.2". The AME Publish tab lists Behance, Facebook, FTP, X, Vimeo and YouTube, not Adobe Stock or
  Creative Cloud.
- **1 status changed:** *Render at Maximum Depth* was folded into a `partial` row with Maximum Render
  Quality. The page shows they are two settings, so the row is split. Maximum Depth (32-bit float
  effects) is `missing`, because the painter is 8-bit. Maximum Render Quality (scaling quality) is
  `have`.

### The one fact that decides most rows

Montagent writes exactly **one deliverable shape**: H.264 (libx264, `yuv420p`, CRF 20, preset
`medium`, `-threads 5`) with AAC at 160 kb/s, 48 kHz stereo, in an MP4 with `+faststart`, at the
project's own `frame` and `fps` (`crates/montagent-render/src/encode.rs`; ADR-0077 §7–8, ADR-0143). The
container is forced with `-f mp4` whatever the `output` path's extension is. ADR-0143 §5 refuses any
project field or CLI/MCP option for the encoder, preset, CRF or thread count. Every other format and
codec in AME's list is therefore `missing` (nothing equivalent, no ADR refusing it), except where an
ADR refuses the mechanism itself.

## Notable gaps

1. **One deliverable shape.** H.264 8-bit 4:2:0 + AAC stereo in MP4 is the only output. Every
   mezzanine and broadcast format (ProRes, DNxHR, CineForm, XAVC, MXF, AS-10/11, DCP, AVI, DV), HEVC,
   MOV and animated GIF are missing. None is refused; ADR-0143 refuses only *knobs on the H.264
   encoder*, and with it presets, rate control and Maximum File Size.
2. **No alpha deliverable.** The encoder takes `rgb24` and writes `yuv420p`, so ProRes 4444 alpha,
   GIF transparency and Render Alpha Channel Only are all missing.
3. **No audio-only export and no channel layouts beyond stereo.** No WAV/MP3, no mono/5.1, and no
   Match Source audio (26.5) or QuickTime channel configuration. This waits on a channel-operations
   capability (ADR-0172).
4. **No HDR, colour-space tagging or HDR10 metadata.** No PQ/HLG, no 10-bit, no Graphics White, no
   tone mapping or SDR Conform.
5. **No output transform.** The deliverable is always the project frame, so export frame size, source
   scaling, crop, rotation, field order and PAR are missing.
6. **No interchange.** FCP XML, EDL, AAF (with its mixdown and audio-stem options), OMF, OTIO and ALE
   are all missing. The project JSON is open, but nothing translates it.
7. **Captions, transcripts and text leave only as pixels.** There is no sidecar (SCC/MCC/XML/STL/SRT),
   no embedded 608/708/OP-47, and no TXT/CSV export. `query --where` reaches the strings as JSON.
8. **No streaming, publishing or review destinations.** No SRT output, social upload, AME Publish,
   Frame.io, or watch folders.
9. **No provenance or file metadata.** No XMP template, markers, start timecode or Content
   Credentials. Only the overwrite-attestation `comment` is written.
10. **Refused on purpose:** hardware encoding and every encoder knob, including presets and Maximum File
    Size (ADR-0143 §2, §5); exporting from proxies (ADR-0067, ADR-0186); parallel encodes (ADR-0108
    §3); LUTs on export (ADR-0040, ADR-0049).
11. **Where Montagent matches or exceeds:** loudness normalisation with a true-peak promise and a
    measured report (ADR-0172/0174), range export (ADR-0121), progress/ETA (ADR-0192),
    cancel-publishes-nothing (ADR-0109), overwrite attestation (ADR-0104), refusing to encode with
    missing media or fonts (ADR-0006), and a post-encode `verify` (ADR-0117).
