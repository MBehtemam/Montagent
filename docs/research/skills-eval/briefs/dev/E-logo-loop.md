# Brief E: logo reveal loop

**6 seconds · 1080×1080 · 30 fps · 1:1.** Deliver one MP4; no sound.

A looping logo sting for Montagent's profile and the end of its videos. It plays on repeat,
so the join has to be invisible: someone watching it loop should not be able to say where it
starts.

Everything you need is in the asset pack; its `README.md` lists it. The mark's exact
construction is there: four shapes on a 2×2 grid. Use the pack's fonts and brand colours.

## Beat by beat

| When | What happens |
|---|---|
| 0 s | An empty frame in the brand's ground colour. |
| 0–2 s | The mark assembles: its four shapes fly in from off-frame one after another and settle into place. |
| on the way in | One of the rounded squares spins three full turns before it settles. |
| ~2.5 s | A text cursor appears to the right of the mark and blinks. |
| ~3–4.5 s | The name **Montagent** types on letter by letter, and the cursor moves ahead of each new letter. |
| 4.5–5.5 s | Everything holds, then clears. |
| 6 s | The frame is empty again, identical to the first frame, so the loop is seamless. |

## Acceptance checklist

- [ ] The mark is built from four separate shapes that arrive one after another, not all at once.
- [ ] One rounded square visibly turns three full times (1080°) on its way in, and settles upright.
- [ ] Assembled, the mark matches the pack's construction: three ink tiles and one accent circle, top right.
- [ ] The cursor blinks with a hard on/off, not a fade.
- [ ] "Montagent" appears one letter at a time, in order, with the cursor ahead of each letter.
- [ ] The last frame matches the first, and the loop has no visible jump.
