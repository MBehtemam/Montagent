# After Effects census: text

Research for [#900](https://github.com/MBehtemam/Montagent/issues/900), on the map
[#896](https://github.com/MBehtemam/Montagent/issues/896). It lists what Adobe documents about
text in After Effects, one row per feature, and scores each feature against Montagent at `main`
`51aa4b5`.

**AE version.** After Effects 26.x. Adobe's What's new page names 26.5 (September 2026) as the
current release; variable font axes arrived in 26.2 (April 2026) and the variable-font filter in
26.3 (June 2026) ([What's new][ae-new]).

**Sources.** Adobe's After Effects user guide on helpx.adobe.com, and nothing else on the AE side:
[Creating and editing text layers][ae-layers], [Formatting characters and the Character
panel][ae-char], [Formatting paragraphs and the Paragraph panel][ae-para], [Animating
text][ae-anim], [Examples and resources for text animation][ae-anim-ex], [Working with variable
font axes][ae-vf], [Creating shapes][ae-shapes], [Track mattes][ae-tm], [Extrude text and shape
layers][ae-extrude], [Apply materials to 3D text and shapes][ae-materials], [Work with Motion
Graphics templates][ae-mogrt], [Work with Essential Properties][ae-ep], [Data-driven
animation][ae-data], [Text effects][ae-text-fx], [Obsolete effects][ae-obsolete], [Effects and
animation presets][ae-presets] and [Expressions: text properties][ae-expr-text].

**How the AE pages were read.** The first draft was written from search-index excerpts while
helpx.adobe.com was blocked. On 2026-10-10 every row was verified against the live pages, fetched
whole: each link below is the canonical URL Adobe redirects to, each feature is on the page it links,
and the "Text" section of the user guide's table of contents was walked for features the draft
missed. Features the live guide does not document for After Effects were removed (collection-face
choice, hyphenation, the Middle Eastern composers and kashida, vertical Roman alignment, and OpenType
feature tags other than ligatures). One row stays unverified: the Stroke Color and Stroke Width
animator properties, which no page of the current guide names (the Animating text page's list stops
at Blur), so the row rests on the app's Animate menu rather than on Adobe's documentation.

**Statuses.** **covered**: Montagent does it. **partial**: some of it. **reachable**: a skill script
or a documented workaround gets the result. **open map**: owned by
[#591](https://github.com/MBehtemam/Montagent/issues/591) or
[#795](https://github.com/MBehtemam/Montagent/issues/795). **refused**: an ADR says no. **gap**:
nothing in the repo does it or decides it (checked by grepping `docs/adr/`, `CONTEXT.md`,
`crates/montagent-core/docs/format*.md`, `skills/` and `schema/`). "Deferred" in an ADR means it
was not decided, so it scores **gap** and names the ADR.

Montagent words follow `CONTEXT.md`: an AE "text layer" is a `text` **element**, a "character" is a
**letter** (one grapheme cluster), an animator's per-character motion is a **stagger** over
**units**, and AE's "tracking" is **letter spacing**.

## Text layers and type

| Feature | What it does | Adobe doc | Montagent status | Evidence |
|---|---|---|---|---|
| Point text | One line per typed break; the box grows with the text. | [layers][ae-layers] | covered | A `text` element with `runs`; a `\n` inside a run is the only break ([ADR-0008][0008]; `format/text.md` "Text"). |
| Paragraph text | Text wraps inside a bounding box; resizing the box reflows it. | [layers][ae-layers] | refused by ADR-0007, ADR-0008 | "Literal `size`. No fit-to-box. No automatic wrapping" ([ADR-0007][0007]); "no wrap policy field is ever added" ([ADR-0008][0008]). Breaks are the agent's, sized with `measure`. |
| Convert point and paragraph text | Switch a layer between the two kinds. | [layers][ae-layers] | refused by ADR-0008 | Follows from the row above: there is one kind. |
| Multiple styles in one layer | Each character can carry its own font, size and colour. | [char][ae-char] | covered | Runs carry `font`, `size`, `color`, `stroke`, `stroke_width`, `dir`, `highlight` (schema `Run`; CONTEXT **Run**). |
| Convert Photoshop text to editable text | Layer > Create > Convert to Editable Text turns an imported Photoshop text layer into an AE text layer, keeping its style. | [layers][ae-layers] | gap | No layered-file import exists; it is a charting candidate on #896 ("layered PSD/AI import"), not a text decision. |
| Text effects: Numbers, Timecode | Effects that draw counters, dates or timecode as text. | [text effects][ae-text-fx] | reachable | Write the values as literal text elements, one per span, generated by a script (SKILL.md loop step 3, "generate it with a script when the structure repeats"). |
| Path Text effect (obsolete) | The old effect for text on a curve. | [obsolete][ae-obsolete] | covered | Replaced in AE by Path Options; in Montagent by text on a path ([ADR-0161][0161]). |

|---|---|---|---|---|
| Font family and style | Pick a family, then a style (Bold, Italic...) from it. | [char][ae-char] | covered | A **font** is a chain of files under a name; a style is a different file, so a different chain entry ([ADR-0007][0007] "No `weight`, no `bold`"; CONTEXT **Font**, **Face**). |

## Character panel

| Feature | What it does | Adobe doc | Montagent status | Evidence |
|---|---|---|---|---|
| Font size | Type size per character. | [char][ae-char] | covered | `size` on the element and on runs, literal pixels ([ADR-0007][0007]). Not keyable (`format.md` animatable list); scale the element instead. |
| Fill colour | Colour of the glyphs. | [char][ae-char] | covered | `color`, keyable on the element, static on runs; a gradient paint is allowed ([ADR-0149][0149]; `format.md` animatable list). |
| Stroke colour and width | An outline around the glyphs; AE centres it on the glyph path. | [char][ae-char] | covered | `stroke`, `stroke_width` on element and runs; the stroke falls outside the contour; keyable on the element ([ADR-0014][0014]; `format/text.md`). |
| Fill over stroke / stroke over fill; All Fills Over All Strokes | Choose which paint is on top, per character or for the layer. | [char][ae-char] | partial | One fixed order: the stroke pass, then the fill pass, so fill is always over stroke (`format/text.md`, units paragraph; [ADR-0014][0014]). No switch. |
| Stroke line join (miter, round, bevel) | Corner shape of the text stroke. | [char][ae-char] | refused by ADR-0158 | "Text takes none of the five ... falls outside the glyph contour with round joins" ([ADR-0158][0158]). |
| Kerning: Metrics | Use the font's own pair kerning. | [char][ae-char] | covered | Shaping applies the font's kerning; ADR-0151 exists so a tracked title keeps "shaping, kerning and alignment" ([ADR-0151][0151]). CONTEXT **Letter spacing** _Avoid_: "kerning (the font's own pair adjustment)". |
| Kerning: Optical and manual pair kerning | AE computes pairs from shapes, or you set one pair by hand. | [char][ae-char] | refused by ADR-0151 (for now) | A per-run spacing override is "Refused for now: ... a word with its own tracking can be its own element" ([ADR-0151][0151]). Optical kerning has no row anywhere. |
| Tracking | Even spacing across a range of characters. | [char][ae-char] | covered | `letter_spacing`, thousandths of an em, keyable, element-level ([ADR-0151][0151]; CONTEXT **Letter spacing**). Range-level tracking is the refusal above. |
| Leading | Distance between lines. | [char][ae-char] | covered | `line_height`, a tenths multiplier of the largest run `size`, static ([ADR-0028][0028]; CONTEXT **Line height**). |
| Top-to-top and bottom-to-bottom leading | Choose where leading is measured from (a CJK option in the Paragraph panel menu). | [char][ae-char] | partial | One fixed measure: each line's slot is the largest run `size` × `line_height` (CONTEXT **Line height**). No switch. |
| No Break | Keep selected characters on one line, so they also animate together as one word. | [char][ae-char] | partial | Keeping a line together is moot: the agent writes every break ([ADR-0008][0008]). Animating two words as one has no counterpart: a `word` unit is a UAX #29 segment, and a no-break space still separates two ([ADR-0151][0151]). |
| Baseline shift | Raise or lower selected characters. | [char][ae-char] | gap | No key in schema `Run` or the text element; no ADR mentions it (grep "baseline shift": none). |
| Tsume | Tighten the space around each character without scaling it. | [char][ae-char] | gap | Nothing in schema or ADRs (grep "tsume": none). `letter_spacing` is uniform, not per glyph proportional. |
| Horizontal and vertical scale | Stretch characters horizontally or vertically. | [char][ae-char] | partial | The element's `scale` is `[sx, sy]` and keyable, which stretches the whole element; a unit's `scale` stretches one unit ([ADR-0151][0151]). No per-run stretch. |
| Faux Bold, Faux Italic | Synthesise a style the font lacks. | [char][ae-char] | refused by ADR-0007 | "`bold: true` can only mean synthetic emboldening, which is renderer-specific ... the schema must reject it" ([ADR-0007][0007]). |
| All Caps | Show text in capitals. | [char][ae-char] | reachable | Write the run's text in capitals. There is no case transform; the text is the content. |
| Small Caps | The font's small caps, or faux ones. | [char][ae-char] | gap | No OpenType feature control (below) and no synthesis ([ADR-0007][0007]). Reachable only with a font file whose default glyphs are small caps. |
| Superscript, Subscript | Raised or lowered smaller characters, real or faux. | [char][ae-char] | gap | Needs baseline shift or the `sups`/`subs` features; neither exists. A smaller run sits on the same baseline. |
| Ligatures | Turn the font's ligatures on or off with the Ligatures option. | [layers][ae-layers] | partial | Decided by a rule, not a switch: optional ligatures on by default, off for the whole element under non-zero `letter_spacing` or a letter stagger; joining scripts keep theirs; `rlig` always on ([ADR-0151][0151], [ADR-0153][0153]; `format/text.md`). |
| Paste Text Formatting Only, Paste Text and Match Formatting | Copy one layer's or word's formatting to another, or paste text that takes the destination's formatting. | [layers][ae-layers] | covered | An agent copies the run's style keys by exact-string edit (`format.md` editing model). App command, no format meaning. |
| Smart quotes | Typed straight quotes become curly ones. | [char][ae-char] | reachable | Write the curly quotation marks as the run's characters; text is raw UTF-8 content and nothing tidies it ([ADR-0007][0007] "Text bytes"). |
| Hindi digits | Show digits in their Devanagari forms (the Digit Set attribute). | [layers][ae-layers] | reachable | Write U+0966 to U+096F directly; the run's text is the content, and no digit-substitution switch exists. |
| Expressions on text style (`style.setFont` and the rest) | Set font, size, fill and paragraph attributes by expression. | [expr text][ae-expr-text] | refused by ADR-0145 | Expressions and value links are refused ([ADR-0145][0145]; SKILL.md "Not by design"; [ADR-0017][0017]). |

## Text animators: properties

AE adds an animator group to a text layer: properties set to the value they reach on selected
characters, and selectors that choose how much each character is affected ([Animating
text][ae-anim]). Montagent's counterpart is the stagger: a `units` block whose lists run once per
unit, each delayed by `every` ([ADR-0151][0151]; CONTEXT **Stagger**, **Unit**). Adobe's Animating
text page lists Anchor Point, Position, Scale, Skew, Rotation, All Transform Properties, Line Anchor,
Line Spacing, Character Offset, Character Value, Character Range and Blur; Opacity, Fill Color and
Tracking appear in its examples page, Font Axis on the variable-font page, and Inter-Character
Blending and Fill & Stroke on the Character panel page. Stroke Color and Stroke Width appear on no
page.

| Feature | What it does | Adobe doc | Montagent status | Evidence |
|---|---|---|---|---|
| Position | Moves each selected character. | [anim][ae-anim] | covered | Unit lists `x`, `y` (`format/text.md` "A `units` block"). |
| Scale | Scales each character. | [anim][ae-anim] | covered | Unit list `scale` (`[sx, sy]`). |
| Rotation | Turns each character. | [anim][ae-anim] | covered | Unit list `rotation`. |
| Opacity | Fades each character. | [anim-ex][ae-anim-ex] | covered | Unit list `opacity`; a fading unit fades as one group ([ADR-0151][0151]). |
| Anchor Point | Moves the characters' pivot. | [anim][ae-anim] | partial | `units.origin`, one of the nine keywords, static ([ADR-0151][0151]). No offset and no keying. A free point is on [#591](https://github.com/MBehtemam/Montagent/issues/591) but "not accepted on text". |
| Skew, Skew Axis | Slants each character. | [anim][ae-anim] | refused by ADR-0167 | "Skew, corner pin, a camera, depth sorting. Still refused" ([ADR-0167][0167]). |
| Fill Color | Recolours selected characters; Adobe's example keys its Hue channel. | [anim-ex][ae-anim-ex] | refused by ADR-0151 (per unit); partial by highlight | "No unit paint. A unit cannot vary `color` or `stroke`" ([ADR-0151][0151]). A timed recolour of one run is a **highlight** ([ADR-0048][0048]). |
| Stroke Color, Stroke Width (unverified) | Changes the outline per character. | none (no page of the current guide names them) | refused by ADR-0151 (per unit) | As above. Element-level `stroke` and `stroke_width` are keyable (`format.md`). |
| Tracking (with Line Anchor) | Animates spacing between selected characters; Line Anchor sets each line's tracking alignment. | [anim-ex][ae-anim-ex] | partial | Element-level `letter_spacing` is keyable; no spacing is added after a line's last letter, so `align` holds ([ADR-0151][0151]). Per-range tracking is refused for now (same ADR); no Line Anchor choice. |
| Line Spacing | Animates the distance between lines. | [anim][ae-anim] | gap | `line_height` is not in the animatable list (`format.md` "Animatable properties"); ADR-0151 adds only `letter_spacing`. |
| Character Offset | Shifts each character by n Unicode steps, to scramble then resolve text. | [anim][ae-anim] | reachable | Text content is static per element; a scramble is a run of abutting text elements, written by a script in the manner of `skills/montagent-motion/scripts/type_on.py`. |
| Character Value, Character Range | Replaces characters with one Unicode value; Character Range keeps case and digits in their groups, or allows full Unicode. | [anim][ae-anim] | reachable | As above. |
| Blur (horizontal and vertical) | Blurs each character. | [anim][ae-anim] | gap | Effects attach to whole elements, never to a run (`format/compositing.md`); `blur` is not a unit list ([ADR-0151][0151]). Whole-element keyed `blur` is covered. |
| Font Axis | Animates a variable-font axis per character. | [variable fonts][ae-vf] | gap (deferred by ADR-0007) | Variable axes are deferred. |
| Enable Per-character 3D, 3D rotation and position | Characters move and turn in 3D. | [anim][ae-anim] | gap; depth refused by ADR-0167 | Projection (`swivel`, `tilt`, `perspective`) is per element; units take no projection lists ([ADR-0167][0167]; `format.md` "Projection"). Z position and a camera are refused there. |
| Orient Each Character Independently | Each character turns about its own anchor to face the active camera. | [anim][ae-anim] | refused by ADR-0167 | "No camera, no depth" ([ADR-0167][0167]); there is nothing to face. |
| Anchor Point Grouping (character, word, line, all) | What unit each character's transform pivots as. | [anim][ae-anim] | covered | `units.by`: `letter`, `word`, `line`; "all" is the element's own transform ([ADR-0151][0151]). |
| Grouping Alignment | Where the pivot sits in each group, as a percentage. | [anim][ae-anim] | partial | `units.origin` nine keywords; no percentage. |
| Fill & Stroke (per character, per group) | How fills and strokes stack across characters. | [char][ae-char] | partial | Fixed: stroke pass then fill pass; a fading unit draws its stroke and fill into one layer ([ADR-0151][0151]). |
| Inter-Character Blending | Blend mode between overlapping characters. | [char][ae-char] | gap | `blend` is element-level only (CONTEXT **Blend mode**); characters inside one element composite normally. |

## Text animators: selectors

| Feature | What it does | Adobe doc | Montagent status | Evidence |
|---|---|---|---|---|
| Range selector Start, End, Offset | The span of characters the animator affects; keying it sweeps the effect across the text. | [anim][ae-anim] | partial | A forward or reverse sweep at a constant rate is a stagger: `every` and `order` ([ADR-0151][0151]). Only an evenly spaced sweep: a key on Start that accelerates has no counterpart except per-unit `delay` overrides in split runs. |
| Units (percentage, index) | How Start and End are measured. | [anim][ae-anim] | covered | Units are counted by index; a unit's delay is its position times `every` (CONTEXT **Unit**). |
| Based On: characters, characters excluding spaces, words, lines | What a selector counts. | [anim][ae-anim] | partial | `by: letter` is "characters excluding spaces"; `word` and `line` match. Counting spaces as steps is excluded by design ("whitespace takes no step", [ADR-0151][0151]). |
| Mode (add, subtract, intersect, min, max, difference) | Combines several selectors. | [anim][ae-anim] | gap | One `units` block per element and no selector algebra. Not discussed in any ADR. |
| Amount | How strongly the properties apply (0 to 100 %). | [anim][ae-anim] | partial | The list values are the amount; no separate scalar to key. |
| Shape (square, ramp up, ramp down, triangle, round, smooth) | The falloff of the selection across the characters. | [anim][ae-anim] | partial | Square with a sweep is a stagger. Ramp, triangle and round falloffs (characters partly affected at rest, or affected by distance from a moving centre) have no counterpart; centre-out order is "Not now" in [ADR-0151][0151]. |
| Smoothness | How long each character takes to change under Square. | [anim][ae-anim] | covered | The span of the unit list against `every`. |
| Ease High, Ease Low | Ease into fully selected and out of fully excluded. | [anim][ae-anim] | partial | Each unit list key has its own `ease` ([ADR-0151][0151]). The ease of the selection across space is the stagger's even spacing. |
| Randomize Order, Random Seed | Applies the animator to characters in random order. | [anim][ae-anim] | refused by ADR-0151 | "A random order, even with a literal seed. Refused"; a literal permutation list is named as the admissible shape, "recorded here, not decided" ([ADR-0151][0151]). |
| Wiggly selector (wiggles per second, correlation, temporal and spatial phase, lock dimensions) | Varies the selection randomly over time. | [anim][ae-anim] | refused by ADR-0156, ADR-0151 | "Camera shake and wiggle. Refused: they are procedural motion the file would not show" ([ADR-0156][0156]); random order refused ([ADR-0151][0151]). A script could bake literal per-unit `delay`s and lists. |
| Expression selector | An expression decides each character's amount. | [anim][ae-anim] | refused by ADR-0145 | Expressions refused ([ADR-0145][0145]; SKILL.md "Not by design"). |
| Several animators on one layer | Stack animator groups, each with its own selectors. | [anim][ae-anim] | gap | One `units` block per text element ([ADR-0151][0151] "may carry one"). A second motion is a second element, or a run's per-unit override. |
| Single out one character | Give one character its own timing or motion. | [anim][ae-anim] | covered | Split the unit into its own run carrying `unit` ([ADR-0151][0151]; CONTEXT **Run**). |

## Gaps worth a decision ticket

Grouped by what a decision would settle. Each names what Montagent has today and what the ticket
would weigh against ADR-0145's four invariants and the entry test (a capability with no CapCut or
Premiere precedent enters only by a prototype the owner accepts).

**1. Font axes and font-drawn styles.**
- Variable fonts: axis values per run, keyed axes (AE 26.2's headline text feature) and the Variable
  Font Spacing choice that goes with them. Deferred by ADR-0007 because the renderer then could not
  honour them; the question is whether it now can.
- Real small caps, superscript and subscript, which AE takes from the font when it has them. The
  route would be a closed list of OpenType feature tags per run (`smcp`, `sups`, `subs`); today
  only the ligature rule touches features. AE's guide documents no wider feature control (stylistic
  sets, alternates), so the list need not reach further.

**2. Character placement inside a line.**
- Baseline shift, and through it real superscript and subscript.
- Tsume, and range-level tracking or manual pair kerning (ADR-0151 refused a run-level
  `letter_spacing` "for now", naming its precedence rule as the obstacle).

**3. The stagger beyond an even sweep (the #896 charting candidate "range selectors beyond the
stagger").**
- Selector shapes: ramp, triangle and round falloffs, and units partly affected at rest.
- Centre-out and edges-in order (ADR-0151: "Not now ... can enter later by its own ADR").
- Several animators on one element, and selector modes that combine them.
- A literal permutation order, the shape ADR-0151 recorded as admissible but did not decide.
- Unit lists for `blur` and for projection (`swivel`, `tilt`): per-character blur and the flat
  half of per-character 3D. Unit paint stays refused by ADR-0151.
- Keyed `line_height` (AE's Line Spacing animator).

**4. Text as geometry.**
- Glyph outlines to `path` points (Create Shapes from Text), most likely as a skill script that
  writes literal vertices, since masks and mattes from text are already refused.

**5. Writing modes.**
- Vertical text, with tate-chu-yoko. Deferred by ADR-0007; only worth a ticket if a CJK brief
  needs it.

**6. Templates.**
- Whether an exposed-parameter or template construct enters at all (Essential Graphics, `.mogrt`,
  editable Source Text, replaceable media), or whether "the agent edits the file, a script generates
  versions" is the recorded answer. ADR-0001 leaves the door open; no ADR has walked through it.
  Essential Properties ride on the nest, so they wait on #591.

**Not worth a ticket:** upright letters on a curve (switching Perpendicular To Path off), a
fill-over-stroke switch, Line Anchor, a percentage Grouping Alignment, Roman hanging punctuation, a
leading-measure switch, and No Break's grouping of two words into one unit. Each is small, and none
has come up in a brief.
