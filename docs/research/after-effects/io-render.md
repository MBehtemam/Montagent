# After Effects census: import, interpretation, preview, render, export and interchange

Research for [#907](https://github.com/MBehtemam/Montagent/issues/907), on the map
[#896](https://github.com/MBehtemam/Montagent/issues/896). It reads published sources and ran nothing.

**Date of research:** 2026-10-10. **AE version read:** the current After Effects user guide on
helpx.adobe.com, i.e. the 26.x line. Adobe's What's New page shows 26.5 (September 2026) as the
latest release. 26.2 (April 2026) added SVG import and Lossless Compressed Playback, 26.3 (June 2026)
added SVG paste as shapes, and 25.2 (April 2025) added FBX import. **Montagent version scored:**
`main` at `51aa4b5` (v0.2.0).

**How the Adobe pages were read.** This environment's egress proxy refuses `helpx.adobe.com`
(CONNECT 403, a policy denial), so no page could be fetched directly. Every Adobe claim below
comes from search-engine extracts of Adobe's own pages: searches limited to `helpx.adobe.com`,
quoting the page text. Each row links the Adobe page the claim came from. Where Adobe's regional
copies or old and new pages disagree, the row says so. Before anyone builds on a figure in this
file, re-read that page in a browser. Bodymovin is a third-party plug-in (airbnb's `lottie-web`), so
its row cites that project rather than Adobe.

**Montagent sources:** `CONTEXT.md`, `docs/adr/`, `crates/montagent-core/docs/format.md`,
`README.md`, `skills/montagent/SKILL.md` (the capability map and its "Not by design" list),
`skills/montagent-prerender`, `skills/montagent-footage`, `schema/montagent.schema.json`, and for
three facts the code itself: still decoding (`crates/montagent-render/src/canvas.rs`,
`Raster::decode`), the decode pixel format (`crates/montagent-render/src/decode.rs`) and the
encoder arguments (`crates/montagent-render/src/encode.rs`).

**Statuses:**
- **covered**: Montagent reaches the result.
- **partial**: it reaches some of the result.
- **reachable**: reachable by a skill or a workaround.
- **open map #N**: an open map owns the question.
- **refused (ADR-NNNN)**: an ADR refuses it.
- **gap**: nothing reaches it and no decision has been recorded.
- **out of scope**: app-only.

Each "gap" below was checked by grepping the ADRs, `CONTEXT.md`, `format.md`, the schema and the
skills for the feature's terms first.

| Conform / assume frame rate | Re-times footage to a stated rate (15 fps conformed to 30 plays twice as fast); sets a sequence's rate | [Importing and interpreting footage](https://helpx.adobe.com/after-effects/using/importing-interpreting-footage-items.html) | **partial** | `speed` re-times a clip against its source range ([ADR-0020](../../adr/0020-speed-overrun-hold-loop.md)), and `source_time` curves it ([ADR-0157](../../adr/0157-a-speed-ramp-is-a-time-remap-curve-of-source-times-on-a-video-element.md)). | Fields and pulldown: separate fields, field order, remove 3:2 / 24Pa, Guess pulldown | De-interlaces and removes telecine cadence | [Video and audio](https://helpx.adobe.com/after-effects/using/importing-interpreting-video-audio.html) | **gap** | No field or pulldown handling. | Colour profile / media colour space (ICC, or OCIO "Interpret Footage > Color") | Tags footage with its colour space for conversion into the working space | [Managing color](https://helpx.adobe.com/after-effects/using/color-management.html); [OCIO and ACES](https://helpx.adobe.com/after-effects/desktop/adjust-colors/opencolorio-and-aces-color-management/opencolorio-aces-color-management.html) | **gap** | No colour management. | Replace / reload / relink footage | Swaps an item's file everywhere, picks up outside edits, relinks missing files | [Footage items](https://helpx.adobe.com/after-effects/using/footage-items.html) | **covered** | `source` is written on the element ([ADR-0002](../../adr/0002-inline-source-no-asset-table.md)), so a replace is a text edit. No user-attached proxy files, and no low-res stand-in for decode cost |

## Gaps worth a decision ticket

Grouped by the decision that would settle them. These are only the gaps a brief can lean on.
The rest are listed at the end with the reason they are left off.

**1. The deliverable's shape: one H.264 MP4, or more than one output.** These go together because
ADR-0143 refused encoder knobs without ever weighing a second output family.
- **An alpha deliverable** (straight or premultiplied). It is the AE feature an agent's brief is
  most likely to ask for: a lower-third or logo sting to drop into another editor. The lossless
  codec is already measured: PNG-in-MOV `rgba`, #723.
- **An image-sequence deliverable** (PNG, maybe EXR).
- **A codec choice** beyond H.264, such as ProRes or HEVC. Shared with Premiere's #892, so decide
  it once across both maps.
- **Output resize or crop.**
- **Fractional frame rates** (`fps` is an integer, so 23.976 and 29.97 cannot be written). This is
  a schema question as much as an output one.

**2. Colour: bit depth, colour management and HDR.** This joins #896's existing candidate.
- 8-bit sRGB bytes everywhere. No source colour profile, no linear working space, no 16 or 32 bpc
  output, no HDR in or out, and nowhere for multichannel EXR data to go. One root, five rows.

**3. Layered and vector import.** This joins #896's existing "layered PSD/AI import" candidate.
- Layered PSD as elements, layered AI and "shapes from vector layer", and Save Frame As Photoshop
  Layers. A skill script that writes ordinary `image` and `path` elements (the duck.py pattern,
  ADR-0177) would keep the format untouched. SVG stays refused by ADR-0171.

**4. Source interpretation overrides.**
- Alpha interpretation overrides (ignore, premultiplied with a matte colour, invert).
- An "assume this frame rate" override for sources whose metadata is wrong.
- Fields and pulldown removal, which ADR-0141 records as unmeasured.
- Each one needs a CapCut or Premiere precedent check under ADR-0145 first.

**5. Cut detection as a skill.**
- Scene Edit Detection written as a skill script that emits literal cuts or split `video`
  elements. Weigh it against the audio map's ruling that detector-driven features are out of scope.

**6. Project packaging.**
- A "collect" step that copies a project with its sources and fonts into one folder. It may simply
  fall out of #656's workspace sync, so check there before ticketing it here.

**Left off on purpose:**
- **GPU.** An engine lever ADR-0010 left unused, not something an author writes.
- **Camera raw and TIFF, PSD or HEIF stills.** Converting the file to PNG first is enough.
- **Lottie export.** Probably a recorded "no": Montagent is a video editor (ADR-0003), and ADR-0171
  already found Lottie's spec and players too weak to trust as an input.
